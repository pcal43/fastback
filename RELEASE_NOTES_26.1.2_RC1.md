# Fastback 0.30.1+26.1.2 RC1

This is a pre-release candidate for Fastback targeting Minecraft 26.1.2 on Fabric.

## Status

This release candidate is working in my local testing, with no major bugs currently known from my testing. It should still be treated as pre-release software.
No major errors when running with:
c2me-fabric-mc26.1.2-0.3.7+alpha.0.67
Chunky-Fabric-1.4.58
DistantHorizons-3.0.2-b-26.1.2-fabric-neoforge

## Target environment

- Minecraft: 26.1.2
- Fabric Loader: 0.19.2
- Fastback version: 0.30.1+26.1.2-rc.1
- Loader/platform: Fabric

## Important notes

- This is not an official upstream Fastback release, I even haven't changed the version number.
- Test on a staging server before using on a production world.
- Make independent backups before testing restore workflows.
- This build is provided as a release candidate for testing and feedback.
